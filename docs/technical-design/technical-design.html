01Architecture

System architecture

One Next.js app on Vercel. The browser scores roles on the device; route handlers own accounts, files, applications and AI calls.

  • Secrets (OpenRouter key, Blob token, session secret) live only in server environment variables.
  • The same matching engine runs in the browser (instant ranking) and on the server (trusted scores for employers and the AI prompt).
